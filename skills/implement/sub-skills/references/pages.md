# Page reference catalog

Page types define the page's contract, content priorities, and component candidates. For page construction or changes, execution belongs to [page](../page.md).

The [page contract](pages/references/contract.md) defines shared page responsibilities; [quality gates](pages/references/quality-gates.md) cover page-wide acceptance. [Delivery and localization](pages/references/delivery-localization.md) applies across origins, deployments, languages, or markets.
