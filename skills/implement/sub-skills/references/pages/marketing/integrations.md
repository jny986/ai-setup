# Integration, Plugin And Connector Pages

## Scope

This family explains how the product works with another product, host, or data source. Integration is the umbrella; a plugin installs into a host, while a connector emphasizes authentication and data exchange.

## Index Mode

Support discovery by category, product, capability, status and availability. Distinguish live, beta, planned, deprecated and partner-owned integrations.

## Detail Modes

Explain connected products, supported use cases, prerequisites, authentication, permissions, data direction, sync timing, setup, limitations, errors, security boundary, ownership, removal and support. Plugin details also cover host versions and lifecycle; connector details emphasize fields, direction and conflict behavior.
