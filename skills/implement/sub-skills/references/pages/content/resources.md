# Resource Pages

## Scope

Resource pages help users discover, evaluate, and obtain maintained educational or practical assets. Content strategy decides what resources exist; this reference covers their website surfaces.

## Modes

- **Hub:** orient across resource types and major themes.
- **Category:** browse one resource type or topic with filters, pagination, and useful category context.
- **Detail:** explain one asset, show a preview, attribution, update status, use instructions, and related resources.
- **Gated:** collect only justified information, record consent, and deliver the promised asset through a real success path.
