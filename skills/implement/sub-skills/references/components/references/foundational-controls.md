# Foundational controls

Button, Link, Input, Textarea, Select, Checkbox, Radio Group, Switch, Slider, Label, and Form are component concepts.

| Source | Fit |
|---|---|
| Project design system | Existing primitive satisfies the interaction and semantic contract |
| Maintained accessible library | Project primitive is absent or cannot meet the required contract |
| Custom implementation | Existing stack cannot satisfy the contract, or foundational construction is explicitly requested |

Visual treatments such as a gradient button or glass input remain variants. Separate concepts require a material difference in user task, interaction contract, semantics, data shape, or established discovery intent.
