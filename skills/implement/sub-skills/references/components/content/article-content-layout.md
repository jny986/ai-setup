# Article Content Layout

## Scope

An article content layout composes the reading region and its closely bound supporting elements. It can be placed inside article, documentation, news, or resource pages; it does not own the route, global page shell, or editorial truth.

## Composition

Select from title context, metadata, cover media, summary, table of contents, prose and rich blocks, references, author information, sharing, and related-content handoff according to the parent page and content type.

## Constraints

- Keep the main content visually and semantically dominant.
- Support headings, paragraphs, lists, tables, code, media, embeds, quotations, and references without forcing every item into every article.
- Keep heading anchors, visible content, metadata, and structured publishing data consistent.
- Treat rich HTML and embeds as a security boundary.

## Acceptance criteria

Short and long articles, missing metadata, long titles, narrow screens, media failure, and embeds preserve readable content. Heading anchors and keyboard navigation work; code and tables have usable overflow, including supported print or reader modes.
