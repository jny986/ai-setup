# Component reference catalog

Component references define responsibility, behavior, variants, and acceptance cases. For component construction or changes, execution belongs to [component](../component.md).

The [component contract](components/references/contract.md) defines shared ownership and state decisions; [quality gates](components/references/quality-gates.md) cover cross-component acceptance. [Foundational controls](components/references/foundational-controls.md) covers inputs and actions; [page boundaries](components/references/pagina.md) distinguishes a component from a complete page.
