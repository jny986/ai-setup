# Migration Pages

## Shared Responsibility

Migration pages help users move from a source platform or format into the product. They are distinct from Comparison pages: the user is preparing to switch, not merely choosing an option.

## Index Mode

Show supported sources, what can move, available automated or assisted paths, broad limitations, and a route to the correct source-specific guide.

## Detail Mode

Define one source system, prerequisites, field and capability mapping, automatic and manual scope, unsupported data, preparation, execution, validation, rollback or recovery, and support.

## Components And Verification

Grid, Card, Comparison Table, How-to Section, Tabs, FAQ, CTA Section, and Announcement Banner may apply. Require confirmed migration capability; never promise all-data migration. Verify sample exports or APIs, authentication, rate limits, duplicate behavior, media, redirects, validation, failure recovery, version differences, and current support ownership.
