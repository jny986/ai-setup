# Design

A router skill for visual design work. It includes workflows for product context, design briefs, visual system documentation, brand kits, interface audits, task flows, UI consolidation, and interface refinement, plus references by design surface.

## Install

```sh
npx skills add jny986/ai-setup --skill design
```
