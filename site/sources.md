## How sources are recorded

Repository sources come from `based_on_repo` metadata across shipped skills, sub-skills and reference documents. Repeated repositories are combined. Website sources come from an explicitly reviewed list of source statements in those files; incidental outbound links and unused upstream submodules are excluded.

Expand a source to visit it and see the affected skills. Filter by a source name or a skill name. Original license and provenance details remain in the linked repository files.
